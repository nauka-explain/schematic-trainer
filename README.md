Симулятор «Чтение схем и печатных плат»
Видишь печатную плату — собери по ней схему. Слева 3D-модель платы (вращение, масштаб, слои),
справа окно схемы в стиле KiCad, где нужно провести провода. Кнопка «Проверить» показывает ошибки:
красный провод — лишнее/неверное соединение, оранжевый пунктир — соединение пропущено.
Запуск
Локально: откройте `index.html` двойным кликом (Chrome, Edge, Firefox, Safari — актуальные версии). Сервер не нужен, интернет не нужен.
На сайте: загрузите всю папку на любой статический хостинг (GitHub Pages, Netlify, обычный hosting). Все пути относительные.
Состав
Файл	Назначение
`index.html`, `css/style.css`	интерфейс
`js/app.js`	режимы, проверка, панель результатов, подсказки, автосохранение
`js/editor.js`	редактор схемы (SVG): символы KiCad, провода, узлы, пан/зум, undo/redo
`js/checker.js`	сравнение собранной схемы с эталонным списком цепей
`js/viewer3d.js`	3D-просмотрщик (three.js)
`js/pcb_model.js`	3D-модель платы (из STEP, сжата gzip+base64)
`js/sch_data.js`	символы, компоненты и эталонные цепи (из .kicad_sch)
`js/three.min.js`, `js/OrbitControls.js`	three.js r147 (лицензия MIT), лежит локально
`tools/`	скрипты конвертации STEP и KiCad для добавления других плат
Возможности
Панель компонентов слева от холста: перетащите символ (или кликните по карточке), счётчик «0/6» показывает, сколько штук размещено. Убрать компонент: перетащить обратно в панель или Del. Компонентам одного типа обозначение (R1…R6) выбирается в списке над холстом: его нужно определить по плате.
Выделение рамкой (инструмент «Выбор», тянуть по пустому месту): слева направо — только то, что целиком внутри (синяя рамка); справа налево — всё, что задето (зелёная пунктирная). Shift/Ctrl добавляет к выделению, группа двигается и удаляется целиком.
Подписи на схеме всегда горизонтальные и не переворачиваются при повороте или отражении.
Режимы «Экзамен» (без подсказок) и «Обучение» (подсветка компонента на плате, обозначения на плате).
Слои 3D: компоненты, шелкография, дорожки, площадки, просвечивание платы; виды сверху, снизу, изометрия, сбоку.
Провода: протяжка от вывода к выводу, клик-клик, ответвления с узлами, провода следуют за компонентами, поворот/отражение.
Проверка по эталону из KiCad: процент, пропущенные и лишние соединения, неразмещённые компоненты; клик по ошибке подсвечивает детали на плате.
Подсказка, «воздушные связи» эталона, таймер, автосохранение в браузере. Интерфейс на иконках, названия показываются во всплывающих подсказках.
Эталонная схема
Эталон — это список цепей из `js/sch_data.js` (поле `nets`), он вычислен из проводов вашего `.kicad_sch`.
Он лежит в открытом виде, поэтому для публичного экзамена его стоит перенести на сервер.
Добавление другой платы
`python tools/step_to_web.py board.step js/` — создаёт `pcb_model.js` (нужны `cadquery-ocp`, `numpy`).
`python tools/kicad_sch_to_json.py board.kicad_sch sch.json` — разбирает схему, печатает цепи и пишет `sch.json`.
Из `sch.json` собирается `js/sch_data.js` (поля `libs`, `insts`, `nets`; формат см. текущий файл).
Позиционные обозначения в STEP (имена компонентов) должны совпадать с обозначениями на схеме.
